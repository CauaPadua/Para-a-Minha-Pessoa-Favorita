# Para a Minha Pessoa Favorita

Site romântico em HTML, CSS e JavaScript, criado como uma carta digital surpresa.

## Como abrir
1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador.
3. Digite a senha `princesa`.

Mantenha a pasta `fotos` junto com os arquivos para que as imagens apareçam.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `style.css`: aparência e responsividade.
- `script.js`: senha, mensagem secreta, animações e corações.
- `fotos/`: imagens utilizadas no site.

**Observação:** a senha fica no JavaScript do navegador. Ela funciona como parte da brincadeira, mas não é uma proteção real para conteúdo privado.
